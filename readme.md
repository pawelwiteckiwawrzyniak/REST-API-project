# REST API - Contact Management

A backend REST API built with Node.js and Express for contact and user account management. Utilizes MongoDB with Mongoose for data persistence.

## Technologies Used
* Node.js
* Express
* MongoDB / Mongoose
* JSON Web Token (JWT) / Passport-JWT
* Bcrypt
* Multer / Jimp / Gravatar
* Nodemailer
* Swagger 

## Key Features
* **Contact CRUD:** Full create, read, update, and delete operations for contact records.
* **Authentication & Security:** User registration, login, JWT token authorization, and password hashing with Bcrypt.
* **Email Verification:** Account verification workflow using Nodemailer.
* **File Uploads & Avatars:** File upload processing via Multer, automated Gravatar generation, and image resizing using Jimp.
* **API Documentation:** Interactive endpoint documentation with Swagger.
